# TR-YOS Zone · Финансы

Дашборд директора учебного центра: кому и когда напомнить об оплате, кому выплатить зарплату, какие подписки пора оплатить и сколько ушло по каждой категории расходов.

## Что умеет

- **Обзор** — сколько собрать с учеников сейчас, сколько выплатить (зарплаты + подписки), доходы и баланс месяца; списки «Напомнить об оплате» и «Выплатить и оплатить» (просрочено → сегодня → скоро); сводка по группам; ближайшие 7 дней; график доходов и расходов за полгода.
- **Группы** — карточки групп: проект, предмет, преподаватель, расписание, цена, число учеников, кто ещё не оплатил. Группа задаёт цену, схему оплаты и преподавателя для новых учеников.
- **Ученики** — ежемесячная оплата (день месяца) или абонемент на N занятий. Кнопки «Напомнил», «Оплатил», «−1 занятие», архив, поиск, фильтр по группе.
- **Преподаватели** — оклад или оплата за занятие (счётчик проведённых занятий). «Выплатить» записывает выплату и сдвигает дату на месяц.
- **Группы → Таблица оплат** — как лист «Student Payments»: ученики по группам с днём оплаты, по месяцам; зелёное оплачено, красное ожидается в этом месяце (клик записывает оплату).
- **Помесячно** — как лист «monthly»: доходы по группам и индивидуальным ученикам, расходы по категориям (Instagram target, Telegram premium, Zoom и т. д.), внизу итог за месяц. Зарплаты попадают в расходы автоматически. Регулярные подписки с днём списания напоминают о себе на обзоре. Выгрузка в CSV.
- **Календарь** — все оплаты, выплаты и подписки по дням, просроченные выделены.
- **История** — журнал всех операций с фильтрами и выгрузкой в CSV.
- **Настройки** — проекты (направления), валюта (по умолчанию $), за сколько дней напоминать, тема, резервная копия JSON.

## Первый запуск

На пустом обзоре кнопка **«Загрузить TR-YOS Zone из таблицы»** переносит данные из файла Finances (Numbers): 6 групп с днями оплаты, учеников с оплатами за июнь–октябрь 2026, преподавателей, расходы по категориям и подписки. Кнопка **«Подключить Google Таблицу»** настраивает загрузку из Google Sheets.

## Google Таблицы

Сайт умеет брать данные из листов Google Таблицы (Настройки → Google Таблицы → «+ Подключить»).

1. Откройте нужный лист и скопируйте ссылку из адресной строки (в ней есть `gid` листа).
2. Дайте доступ на чтение: Файл → Поделиться → «Все, у кого есть ссылка» (Читатель), либо Файл → Опубликовать в интернете.
3. Вставьте ссылку, выберите, что в листе: ученики, преподаватели, расходы (категория × месяц) или журнал платежей.
4. Проверьте соответствие колонок: сайт угадывает его по заголовкам (Имя, Группа, Преподаватель, Цена, День оплаты, Статус, Телефон, Дата, Сумма, Тип…), любое поле можно поправить вручную.

Ученики и преподаватели сопоставляются по имени, группы создаются автоматически из колонки «Группа». Расходы и журнал платежей заменяются целиком при каждом обновлении. Галочка «Обновлять при каждом открытии сайта» включает автосинхронизацию; кнопка «⟳ Обновить» вверху делает это вручную.

Если браузер не может обратиться к Google напрямую, сайт использует серверную функцию `api/sheet.js` (работает на Vercel автоматически).

## Где хранятся данные

В браузере (localStorage), сервера нет. На вкладке «Настройки» можно скачать копию и загрузить её на другом устройстве.

## Запуск

Статический сайт без сборки: откройте `index.html` в браузере или задеплойте папку как есть (Vercel, Netlify, GitHub Pages).
